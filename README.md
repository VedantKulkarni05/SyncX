# SyncX

SyncX is a side project to build a real-time collaborative code editor. The goal is to learn Docker, AWS ECS, WebSockets, Redis, and scalable system design while shipping a working product.

## Tech stack

- **Frontend:** React, Vite, Tailwind CSS, Monaco Editor
- **Backend:** Node.js, Express, Socket.IO, Yjs (`y-socket.io`)
- **Infrastructure (planned):** Docker, Redis, AWS ECS

## Usage

Requires Node.js 22+.

**Backend** (http://localhost:3000)

```bash
cd Backend
npm install
npm run dev
```

**Frontend** (http://localhost:5173)

```bash
cd Frontend
npm install
npm run dev
```
